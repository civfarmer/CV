# civfarmer.github.io/CV/

This repository serves one page: **Christopher I. V. Farmer's contact card** at
<https://civfarmer.github.io/CV/>, the address printed on his business cards.

The portfolio itself moved to <https://civfarmer.github.io/> (repository
[civfarmer/civfarmer.github.io](https://github.com/civfarmer/civfarmer.github.io)).
Every page that used to live here forwards to the same path there: the HTML pages in this
repository are forwarding pages, and `404.html` sends anything else (the generated Meridian
pages, PDFs, images) to its new address. `docs/` keeps the CV PDF at its old address for links
that cannot run a redirect.
