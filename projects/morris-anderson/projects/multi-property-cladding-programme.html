Multi-Property Cladding Programme

Approximately 1,000 m² of cladding delivered across five properties in Marlborough, requiring consistent installation and coordinated programme management.

The challenge

Multi-property work multiplies the coordination: materials, weather windows, scaffold and labour all have to be balanced across five buildings while the standard of installation stays identical on each.

The approach

The five properties were treated as one programme with shared procurement and a consistent installation specification, so progress on each building supported rather than competed with the others.

Key considerations

  • Consistent installation quality across five buildings
  • Programme sequencing between properties
  • Material call-off and storage across a multi-site programme
