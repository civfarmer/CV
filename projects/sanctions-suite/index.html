Sanctions Suite

four offline tools no network calls Case study Portfolio

Four screening tools built on a single dated OpenSanctions snapshot. Each one opens as a self-contained page, runs entirely in your browser, and answers a real question with real data — no server, no API call, nothing typed here ever leaves the machine.

This is the public demo. It carries a 12,544-record subset of the 308,597-entity production corpus, so it loads quickly over the web. Vessels, the relationship graph and the company screening are complete. The full build runs locally from the same pipeline — every tool states which corpus it is using, and a nil result in the demo is not a screening result.
